# MajoranaPropagation.jl
A Julia library for Majorana propagation simulation of fermionic quantum circuits and quantum systems.
Majorana propagation works in the Heisenberg picture, backpropagating fermionic observables $\hat O$ through the fermionic circuit $\mathcal C$.
It is then possible to compute expectation values with initial states $\rho$ as $\mathrm{Tr}(\rho~\mathcal C^\dagger \hat O \mathcal C)$, or to evaluate inner products between observables, $\mathrm{Tr}(\hat O_1~\mathcal C^\dagger \hat O_2 \mathcal C)$.

The code relies on expanding the initial observable into a basis for fermionic observables, namely the set of Majorana strings $\mu(v)$ $$\hat O =\sum_v \alpha_v \mu(v)$$
To maintain the computation classically feasible, it is essential that the initial observable is sparse in this basis.

The code provides constructors to initialize the most common fermionic observables and operations in the Majorana basis, without the need for the user to perform this mapping manually.

## Usage
To install MajoranaPropagation.jl, you can install the registered package using the following commands in Julia's REPL:
```julia
using Pkg
Pkg.activate("path/to/project")
Pkg.add("MajoranaPropagation")
```
Afterward, include
```julia
using Pkg
Pkg.activate("path/to/project")

using MajoranaPropagation
```
in the script where you want to use Majorana Propagation's functionalities.
### Installing from GitHub
Alternatively, you can install the latest code or some experimental branch using
```julia 
Pkg.add(url="https://github.com/SparqleSim/MajoranaPropagation.jl", rev="branch_name")
```
to install a specific branch `branch_name`.

## Quick start
You can find example scripts in the `examples/` directory of the repository. We currently illustrate the usage for simulating the evolution of observables under the unitary dynamics generated by the Fermi-Hubbard Hamiltonian in 1D and 2D lattices.

Simulating the expectation value of $\langle n_3 n_5\rangle(\tau)$ for a 1D chain of
spinless fermions under the dynamics of the t-V Hamiltonian 
$$H=-t\sum_{\langle i,j\rangle}\left(f^\dagger_if_j+f^\dagger_jf_i\right) + V\sum_{\langle i,j\rangle} n_in_j$$
is done as
```julia
using Pkg
Pkg.activate("path/to/project")

using MajoranaPropagation

# Set parameters
L_sites = 10
t_hop = 1.0
V = 2.0
dtau = 0.1
n_steps = 6

# Create Hamiltonian
topo = bricklayertopology(L_sites)

circ_single_step = []
thetas_single_step = []
for (i, j) in topo
    push!(circ_single_step, FermionicGate(:hop, [i, j]))
    push!(thetas_single_step, -t_hop * dtau)
end
for (i, j) in topo
    push!(circ_single_step, FermionicGate(:nn, [i, j]))
    push!(thetas_single_step, V * dtau)
end


# Set initial Fock state
# specify the sites where fermions are created
fock_state = FockState(L_sites, 1:2:L_sites)

# Set observable 
obs = MajoranaSum(L_sites, :n, 1) * MajoranaSum(L_sites, :n, 5)
@show obs 

# Propagate 
for step = 1:n_steps
    propagate!(circ_single_step, obs, thetas_single_step; min_abs_coeff=1.e-8)
    @show overlapwithfock(obs, fock_state)
end
```
It's also posssible to consider superpositions of Fock states as initial states 
```julia
# Consider a second Fock state that only differs by the position of one fermion
fock_state = fockstate(1:2:L_sites)

sites2 = collect(1:2:L_sites)
sites2[1] = 2
fock_state_2 = FockState(L_sites, sites2)

# Set observable 
obs = MajoranaSum(L_sites, :n, 1) * MajoranaSum(L_sites, :n, 5)

# Propagate
for step = 1:n_steps
    propagate!(circ_single_step, obs, thetas_single_step; min_abs_coeff=1.e-8)
    o1 = overlapwithfock(obs, fock_state)
    o2 = overlapwithfock(obs, fock_state_2)

    # compute the overlap with the equal superposition of the two Fock states
    osuper = overlapwithfock(obs, [fock_state, fock_state_2], [1 / sqrt(2), 1 / sqrt(2)])
    @show osuper
end
```
