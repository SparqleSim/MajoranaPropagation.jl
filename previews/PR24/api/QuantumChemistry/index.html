Quantum Chemistry

Operator Constructors

MajoranaPropagation.QuantumChemistry.four_body_term — Method
four_body_term(nsites, p, q, r, s)

Build the two-body (four fermion-operator) term of a quantum chemistry Hamiltonian for the orbital indices $(p, q, r, s)$: products $f_{p}^\dagger f_{q}^\dagger f_{r} f_{s}$ with the spin patterns $\uparrow\uparrow\uparrow\uparrow$, $\downarrow\downarrow\downarrow\downarrow$, and $\uparrow\downarrow\uparrow\downarrow$, summed over the 8 index permutations under which a real two-electron integral is invariant: $h_{pqrs} = h_{prqs} = h_{sqrp} = h_{srqp} = h_{qpsr} = h_{qspr} = h_{rpsq} = h_{rspq}$. Returns a MajoranaSum with real Float64 coefficients.

source
MajoranaPropagation.QuantumChemistry.two_body_term — Method
two_body_term(nsites::Integer, indices, coeff::CT) where {CT}

Build the one-body (two fermion-operator) term of a quantum chemistry Hamiltonian for the orbital pair indices $= (p, q)$, scaled by coeff: the spin-summed hopping $\sum_{\sigma, \sigma'} (f_{p\sigma}^\dagger f_{q\sigma'} + f_{q\sigma'}^\dagger f_{p\sigma})$ for $p \neq q$, or $\sum_{\sigma, \sigma'} f_{p\sigma}^\dagger f_{p\sigma'}$ for $p = q$.

MajoranaPropagation.QuantumChemistry.parse_fcidump — Method
parse_fcidump(filename; min_coeff=-1.0, remove_identity=true)

Parse a quantum chemistry Hamiltonian from an FCIDUMP file into a spinful MajoranaSum, assembling it from two_body_term and four_body_term (the latter scaled by 1/2). Terms with absolute coefficient smaller than min_coeff are dropped, and the identity component is removed if remove_identity=true.
