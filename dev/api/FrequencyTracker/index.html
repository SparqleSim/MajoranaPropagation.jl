Frequency Tracker

MajoranaPropagation.MajoranaFrequencyTracker — Type
MajoranaFrequencyTracker(coeff)

PathProperties coefficient wrapper tracking the number of splits (freq), sine (nsins) and cosine (ncos) applications along a Majorana propagation path.

source
MajoranaPropagation.reset_tracker! — Method
reset_tracker!(msum)

Reset the freq, nsins and ncos counters of all coefficients to 0, keeping the coefficients.

PauliPropagation.wrapcoefficients — Method
wrapcoefficients(msum, ::Type{MProp}) where {MProp<:PathProperties}

Wrap the coefficients of a MajoranaSum or VectorMajoranaSum into the PathProperties type MProp via its one-argument constructor MProp(coeff).

For VectorMajoranaSum the sorted prefix is preserved. Note that path counters are only exact on the vector backend while merges take the sorted-tail path: the generic fallback merge (unsorted prefix, gate weight > 4) resets the counters of merged terms.
