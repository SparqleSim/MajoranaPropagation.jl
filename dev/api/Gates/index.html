MajoranaPropagation._applymajoranarotation! — Method

For a Majorana string $ms$, the splitting rule for $e^{i \theta G / 2} \, ms \, e^{-i \theta G / 2}$ with gate string $G$ is

  • $ms$, if $[G, ms] = 0$
  • $\cos(\theta) \, ms - i \sin(\theta) \, ms \, G$, if $\{G, ms\} = 0$

Imaginary-Time Rotations

MajoranaPropagation.ImaginaryFermionicRotation — Type
ImaginaryFermionicRotation(symbol::Symbol, sites::Vector{Int})
ImaginaryFermionicRotation(symbol::Symbol, site::Integer)

Structure to represent the imaginary-time evolution $e^{-\beta/2 \, O}$, generated by the observable $O$ defined by symbol acting on sites (with its identity component dropped). Applied to a MajoranaSum $A$ as the two-sided non-unitary conjugation $e^{-\beta/2 \, O} \, A \, e^{-\beta/2 \, O}$. Note that the exponent carries a factor $1/2$, in contrast to the real-time FermionicRotation. Only defined in the Schrödinger picture, i.e. propagate must be called with heisenberg=false. See MajoranaSum(n_sites::Integer, symb::Symbol, sites) for the supported symbols.

source

Structure to represent an imaginary-time Majorana rotation $e^{-\beta/2 \, ms}$, generated by a Majorana string ms of even weight. Applied to a MajoranaSum $A$ as the two-sided non-unitary conjugation $e^{-\beta/2 \, ms} \, A \, e^{-\beta/2 \, ms}$. Only defined in the Schrödinger picture, i.e. propagate must be called with heisenberg=false.

MajoranaPropagation._applyimaginarymajoranarotation! — Method

For a Majorana string $ms$, the splitting rule for $e^{-\beta \, G / 2} \, ms \, e^{-\beta \, G / 2}$ with rotation string $G$ is

  • $ms$, if $\{G, ms\} = 0$
  • $\cosh(\beta) \, ms - \sinh(\beta) \, G \, ms$, if $[G, ms] = 0$

Implement the imaginary-time evolution $e^{-\beta \, O / 2} \, msum \, e^{-\beta \, O / 2}$ for a fermionic gate $O$. If normalize_coeffs=true, the Majorana sum is renormalized after each Majorana rotation such that the identity coefficient stays 1.
